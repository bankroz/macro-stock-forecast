# 股市长周期走势 — 可扩展宏观指标建议

> 基于当前存款信号系统的分析框架，以下指标已被验证可用于辅助判断股市长周期走势。
> 所有指标均通过 akshare 可直接获取（接口已实测），标注了建议优先级和数据可获取性。

---

## 一、信用周期类（强烈推荐，优先级最高）

信用周期是 A 股长周期最核心的驱动因子之一。M2 增速和社融增速的拐点通常领先股市 6-12 个月。

### 1.1 M2 货币供应量

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_money_supply()` |
| **数据列** | M2/M1/M0 数量（亿元）+ 同比增长 + 环比增长 |
| **历史深度** | 约 220 条（回溯至 2008 年），月度 |
| **最新数据** | 2026 年 4 月（实时） |
| **与股市关系** | M2 增速拐点领先上证 6-12 月，是流动性环境的总量指标。M2 增速 > 10% 通常对应牛市环境，< 8% 对应熊市/震荡 |
| **建议用途** | 作为信用周期的核心锚定指标，与存款信号做交叉验证 |

### 1.2 新增人民币贷款

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_rmb_loan()` |
| **数据列** | 新增贷款总额 + 同比 + 环比 + 累计 |
| **历史深度** | 约 30 条（近年数据） |
| **与股市关系** | 信贷脉冲（新增信贷 / GDP）是经典领先指标，脉冲拐点领先股市约 3-6 个月 |

### 1.3 社会融资规模（社融）

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_shrzgm()` |
| **可用性** | 当前接口有 SSL 问题，需降级到东方财富网页抓取或手动补充 |
| **替代方案** | 东方财富数据中心 `data.eastmoney.com/center/macro.html` 手动导出 |
| **与股市关系** | 社融增速是 A 股最经典的领先指标之一，增速拐点通常领先 3-9 个月 |

**优先级排序：M2 > 新增信贷 > 社融**（按数据可获取性排序）

## 二、实体高频类（推荐，优先级高）

这些指标反映实体经济活跃程度，是股市基本面的先行信号。

### 2.1 全社会用电量

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_society_electricity()` |
| **数据列** | 全社会 / 一产 / 二产 / 三产 / 城乡居民用电量 + 同比增速 |
| **历史深度** | 238 条，月度（累计值，含同比） |
| **最新数据** | 2026 年 4 月 |
| **与股市关系** | 用电量是 GDP 的高频替代指标。二产（工业）用电量增速与上证指数相关性高（r ≈ 0.5-0.6），拐点领先约 2-4 个月。第三产业用电量增速近年权重上升 |
| **建议用途** | 构建用电量-股指交叉相关性分析，作为基本面验证维度 |

### 2.2 PMI 采购经理指数

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_pmi()` |
| **数据列** | 制造业 PMI + 非制造业 PMI 指数 + 同比变化 |
| **历史深度** | 220 条，月度，回溯至 2008 年 |
| **与股市关系** | PMI 是国家统计局发布的先行指标，官方研究确认其领先 GDP 约 1 个季度。PMI 连续 3 月高于 50 或低于 50 构成趋势信号 |
| **建议用途** | 作为月度基本面景气度判断的核心指标 |

### 2.3 工业增加值

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_industrial_production_yoy()` |
| **数据列** | 工业增加值年率（今值/预测值/前值） |
| **与股市关系** | 工业增加值是规模以上企业盈利的前置指标，增速拐点领先企业利润 1-2 个季度 |

## 三、市场流动性类（推荐，优先级中）

反映股市自身的资金面状态，是中短期择时的重要参考。

### 3.1 两融余额（融资融券）

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_market_margin_sh()` |
| **数据列** | 融资买入额 / 融资余额 / 融券余额 / 融资融券余额 |
| **历史深度** | 3917 条，日频 |
| **最新数据** | 2026-05-26（近实时） |
| **与股市关系** | 融资余额是散户加杠杆的直接度量，牛市中融资余额加速增长，见顶前 1-2 个月增速放缓。融资余额 / 流通市值 比值在 2.5% 以上需警惕 |
| **建议用途** | 高频日度监控，作为存款信号的日内/周度补充 |

### 3.2 SHIBOR 银行间同业拆借利率

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_shibor_all()` |
| **数据列** | O/N / 1W / 2W / 1M / 3M / 6M / 9M / 1Y 利率 + 涨跌幅 |
| **历史深度** | 2290 条，日频 |
| **与股市关系** | 短端利率飙升代表资金面紧张，往往对应市场下跌。DR007 > 政策利率 50bp 以上时市场承压 |

### 3.3 LPR 贷款市场报价利率

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_lpr()` |
| **数据列** | 1 年期 / 5 年期 LPR + 基准利率 |
| **历史深度** | 1572 条，覆盖 2013 年至今 |
| **与股市关系** | LPR 下调降低实体经济融资成本，利好股市估值；LPR 连续下调周期通常对应牛市启动期 |

## 四、价格与通胀类（辅助参考）

### 4.1 CPI 居民消费价格指数

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_cpi()` |
| **历史深度** | 220 条，月度 |
| **与股市关系** | CPI-PPI 剪刀差影响企业利润传导。温和通胀（2-3%）利好股市，通缩（CPI < 1%）对盈利端形成压力 |

### 4.2 PPI 工业生产者出厂价格

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_ppi()` |
| **历史深度** | 244 条，月度 |
| **与股市关系** | PPI 同比转正往往领先上游周期股行情 1-2 个月。PPI 与 CPI 剪刀差扩大时上游盈利受益 |

### 4.3 进出口数据

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_hgjck()` |
| **数据列** | 出口额 / 进口额 + 同比 + 环比 |
| **与股市关系** | 出口超预期利好外向型企业，但中美贸易摩擦期间出口数据对市场冲击加大 |

## 五、基础设施与物流类（辅助参考）

### 5.1 波罗的海干散货指数 (BDI)

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_freight_index()` |
| **数据列** | BCI / BSI / BDI / BCTI / BDTI 等指数 |
| **历史深度** | 5000 条，日频，回溯至 2006 年 |
| **与股市关系** | BDI 与全球经济周期高度相关，BDI 大幅下跌常预示全球需求走弱，对资源股和出口股有领先指引 |

### 5.2 社会消费品零售总额

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_consumer_goods_retail()` |
| **历史深度** | 205 条，月度 |
| **与股市关系** | 消费数据是内需型企业的直接景气度指标，增速持续下滑预示消费板块压力 |

### 5.3 财政收入

| 项目 | 说明 |
|------|------|
| **akshare 接口** | `ak.macro_china_czsr()` |
| **历史深度** | 212 条，月度 |
| **与股市关系** | 财政收入增速反映企业盈利（尤其是税收部分），是经济基本面的间接度量 |

## 六、其他可扩展方向

| 方向 | 数据源 | 说明 |
|------|--------|------|
| **北向资金** | 东方财富沪深港通 API | 外资流入流出，日频，已验证与大盘短期方向强相关 |
| **新增投资者数量** | 中登公司 | 新开户数暴增是散户入场信号，往往是阶段性顶部 |
| **商品房销售面积** | 国家统计局 | 房地产是信用周期的重要传导渠道，销售数据领先地产链投资 |
| **水泥/钢铁产量** | 行业协会 | 高频开工指标，月度，反映基建和房地产实际投资强度 |
| **央行公开市场操作** | 中国人民银行 | MLF/OMO 净投放量反映央行意图，对流动性敏感板块有指引 |

## 七、建议的接入优先级

| 阶段 | 指标 | 理由 |
|------|------|------|
| **第一批（立即）** | M2 增速、PMI、全社会用电量 | 接口稳定、数据完整、逻辑清晰，可直接入库分析 |
| **第二批** | 两融余额、SHIBOR、CPI/PPI | 补充流动性维度，日频数据适合做高频信号 |
| **第三批** | 新增信贷、BDI、社零、财政收入 | 完善基本面全景图 |
| **第四批** | 社融（需解决接口问题）、北向资金 | 高价值但数据接入有技术难度 |
